# Security Policy

ReceiptMind stores receipts, photos and spending data only on the user's device. Anything
that could expose that data, such as a network path, a leak through exports or shares, or
weak handling of stored files, is a security issue for this project.

## Supported versions

| Version | Supported |
|---|---|
| Latest release | ✅ |
| Older releases | ❌ Please update first |

## Reporting a vulnerability

**Please do not open a public issue.** Report it privately through GitHub:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** (GitHub Private Vulnerability Reporting).
3. Describe the issue, the affected version, and the steps to reproduce it.

You can expect an acknowledgement within 7 days. Once a fix is released, the advisory
is published with credit to you, unless you prefer to stay anonymous.
